# Задание 1. Анализ и планирование

### 1. Описание функциональности монолитного приложения

**Управление отоплением:**

- Включить отопление
- Выключить отопление
- Установить целевую температуру

**Мониторинг температуры:**

- Получить текущее значение температуры
- Получить описание модуля управления: id, состояние (включено\выключено), целевая и текущая температура

### 2. Анализ архитектуры монолитного приложения

* Язык программирования: Java 17, Spring Framework, SpringBoot Web Application<br/>
* База данных: Postgres 13
* Архитектура: Монолитное приложение
* Взаимодействие: Синхронное, запросы обрабатываются последовательно. Ограничивает масштабируемость и отказоустойчивость
* Масштабируемость: Ограничена, так как монолит сложно масштабировать по частям
* Развертывание: Требует остановки всего приложения 
* Обслуживание пользователей: У пользователя нет возможности подключить новые датчики самостоятельно, требуется участие технического специалиста

### 3. Определение доменов и границы контекстов
 
* Домен управления датчиками
* Домен работы с телеметрией
* Домен управления пользователями

### 4. Проблемы монолитного решения

- Ограниченное масштабирование - только через поднятие дополнительных копий ВСЕГО приложения;
- Ограничения на развертывание - любое обновление приложения требует его остановки и полной замены новой версий;
- Ограничения при разработке - несколько команд, которые работают над приложением могу конкурировать при изменении кода;
- Тестирование требует все приложение, даже если была изменена ограниченная функциональность;
- Обновление зависимостей/библиотек необходимо производить для всего приложения;
